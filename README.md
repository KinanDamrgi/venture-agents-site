# Venture Agents — public website

A standalone **informational** GitHub Pages site for the Venture Agents project. This repository deliberately contains only static HTML, CSS, and JavaScript. No local agent source, configuration, tokens, user data, private logs, or Master Bot files are included.

- A free browser-side CSV-to-JSON demo (`index.html` + `demo.js`).
- Accurate descriptions of three Python toolkit prototypes from Venture Agents v5.2.
- About, contact, privacy and terms pages.
- No storefront checkout, order forms, payment acceptance, or claims of operating as a registered company.

The linked Python toolkit itself is not published here. Do not add private project configuration or secret keys. This is a preview site, not legal or payment-processor approval.
